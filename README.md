# React-SpringBoot-CRUD 🚀

A full-stack CRUD application built using React.js and Spring Boot for managing student records.

## 🛠️ Tech Stack

### Frontend
- React.js
- Tailwind CSS
- Axios
- JavaScript

### Backend
- Spring Boot
- Spring Data JPA
- REST API
- Java

### Database
- MySQL / MongoDB

## ✨ Features

- Add new student
- View all students
- Update student details
- Delete student
- Soft delete student
- REST API integration
- Responsive UI design
